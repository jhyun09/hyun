# 🌧️ RainHyun 감성 게시판

비 오는 날, 한계령을 떠올리며 만든 감성 웹페이지입니다.  
추억, 음악, 이미지, 그리고 마음속 이야기들을 담아내는 공간을 Flask로 구현했습니다.

---

## 📦 프로젝트 개요

- **프레임워크**: Flask (Python)
- **기능**:
  - 감성 게시글 작성 및 조회
  - 배경 음악 자동 재생
  - 이미지 업로드 및 표시
  - Render를 통한 배포
